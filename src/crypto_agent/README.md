# CPQA Crypto Agent

Prepare the upstream native runtime from the CPQA repository root.

```sh
python src/crypto_agent/prepare_upstream.py
```

The command downloads the latest published SDK for the host. See the deployment guide
for pinned releases, source builds, and runtime layout.
